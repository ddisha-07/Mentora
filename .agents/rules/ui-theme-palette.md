# Mentora UI Color Palette & Card Theme Rules

When designing or updating UI components, dashboards, and metrics cards in Mentora, refer to and maintain this distinct card color palette and dual-mode theme aesthetic:

## 1. Modular Color Identity per Section/Card
Instead of generic monolithic cards, give key dashboard cards/modules a distinct, curated color identity:

- **Yellow / Gold Palette**:
  - Used for: "Courses In Progress" / Activity tracking.
  - Accents: Bright warm gold/amber indicators, glowing activity bars (`#F59E0B` / `#FBBF24`), pill badges.
- **Pink / Magenta Palette**:
  - Used for: "Learning Summary & Hours" / Analytics & Time tracking.
  - Accents: Vibrant pink/magenta line graphs, subtle heart background vectors, pink badges (`#EC4899` / `#F43F5E`).
- **Green / Emerald Palette**:
  - Used for: "By Condition & Skill Gaps" / Skill progress & status.
  - Accents: Mint/emerald green badges, condition tags, completion percentages (`#10B981` / `#34D399`).
- **Blue / Indigo Palette**:
  - Used for: "Quiz Performance & Sessions" / Quiz statistics.
  - Accents: Deep electric blue / sky blue metrics, four-point star watermark overlay (`#3B82F6` / `#60A5FA`).

## 2. Dual Mode Adaptability

- **Dark Mode Aesthetic**:
  - Backgrounds: Deep black/dark glass background with subtle colored borders and inner ambient glow.
  - Neon / Glow Effects: Neon glowing bar charts, glowing plot points on smooth splines, high-contrast crisp typography.
- **Light Mode Aesthetic**:
  - Backgrounds: Soft, pastel-tinted containers matching each metric's theme (e.g. warm cream-yellow, light rose-pink, mint pastel green, icy blue).
  - Text & Accents: Dark high-contrast primary text with bold vibrant accent colored metrics.

## 3. Visual Details & Badges
- Pill-shaped status/delta badges (`+1 this month`, `+3.2h vs last week`, `39% Complete`, `+5% this month`) positioned at top right of cards.
- Background watermark vector graphics (e.g. subtle large plus sign, heart outline, geometric shapes, star outline).
- Monospace font for time counters (e.g., `01:30h`, `00:24m`, `07:30 p.m.`).
